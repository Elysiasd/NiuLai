## 1. 主题解码：我们到底在复刻什么

《牛来》现象有四层，本计划的每一个素材都必须能对号入座到其中一层，否则不做：

| 层 | 现象 | 情绪 | 插件里的对应物 |
|---|---|---|---|
| L-a 场外 | 只有一张水墨海报，宣传词「治愈系水墨国风」，零宣发裸映 | 被骗进场的期待 | 海报语素材（§3A） |
| L-b 银幕 | 正片是粗糙低模三维，首日 342 元、第 10 天 7705 元上热搜；观众盗摄劣质画面传遍互联网，成为传播起点 | 第一重震惊 | 正片语素材（§3B） |
| L-c 影厅 | 进场后发现周围全是精神世界抽象的同类：全程开怀大笑，没人关心盗摄，没人维护秩序，影厅变成一场心照不宣的集体行为艺术——这是它真正爆火的原因 | 第二重震惊 → 狂欢、同类相认 | **影厅语素材（§3C，本计划的核心）** |
| L-d 场后 | 「只要合规就能拿龙标发行」：审查只管合规、不评质量，引出对国产电影「劣币驱逐良币」的行业反思 | 笑完之后的沉默 | 反思层素材（§8，克制承载） |

**核心结论：「震惊的抽象艺术」不是把界面弄丑，而是复刻一次完整的《牛来》观影旅程——被海报骗进来（L-a）→ 被画面吓一跳（L-b）→ 环顾四周发现全场都在笑（L-c）→ 散场后想起一点行业的事（L-d）。震惊只是入口，同类狂欢才是主体，反思是余味。**

## 2. 概念宣言：「入场三幕」

一句话概念：**把 dsh Web UI 变成《牛来》的一间影厅。**

用户以为自己在用一个正经编码工具（正如观众以为自己要看一部水墨动画）；插件让他逐步发现——这个工具的状态语在玩梗、完成任务会盖「手搓认证」、弹幕会飘过「哈哈哈哈」、错误页是三只低模狼——周围全是抽象同类，而 agent 本身就是那头牛。

设计铁律：

1. **震惊靠落差与稀缺，不靠高频弹脸。** 三套语言的切换是编排出来的（§7），不是随机的。
2. **狂欢不能伤工具性。** 代码、diff、终端输出等生产界面上，素材出现次数 = 0。
3. **每个素材可关。** 抽象是邀请，不是绑架（详见开关矩阵 §6.4）。

## 3. 三套美术语言规范

### 语言 A · 海报语（水墨国风 —— 场外的承诺）

- **色板**：宣纸 `#f7f2e7 / #f4eddd`、淡墨 `#8a8272`、浓墨 `#2f2a24`、朱砂 `#b3392f`、竹青 `#5a7d4f`、黛蓝 `#3d6e70`（与已上线主题 token 完全一致，保证素材与界面同源）。
- **构型**：大留白、单侧构图、干笔飞白、方形朱文印章；山体用 3–5 段浓淡墨阶。
- **载体**：SVG 为主。纸纹与墨晕用 `feTurbulence` 程序生成，不引入位图纹理。
- **文字**：楷体系统栈（`Kaiti SC / STKaiti / KaiTi`），不嵌入字体文件。
- **禁忌**：不出现语言 B/C 的任何元素——海报语必须「装得毫无破绽」，落差才成立。

### 语言 B · 正片语（手搓低模 —— 银幕上的真相）

- **色板**：默认材质灰 `#9e9e9e`、塑料绿 `#23b45a`、高饱和蓝 `#35a2ff`、警告红 `#ff3b30`、阳光黄 `#ffd23f`。故意不和谐、故意像未调色的引擎默认值。
- **构型**：低多边形（牛 ≤ 200 三角面）、硬边无平滑法线、default-cube 梗、错位 UV 观感、五毛镜头光晕。
- **载体**：两条路线——① 程序化 SVG 低模（`scripts/gen-cow.mjs`，seed 固定后提交产物）；② 循环 WebP 序列帧（对标 dsh-whale-animation 的做法，每个动画配 reduced-motion 静帧）。
- **禁忌**：不做真实的「渲染错误」（假死机、假报错弹窗）——粗糙是美学，不是欺骗用户界面状态。

### 语言 C · 影厅语（盗摄质感 + 满座同类 —— 本计划核心，新增）

复刻「在影厅里」的体验，它有两个子词汇：

**C1 盗摄质感**（画面怎么看）：
- 手机竖屏取景框（圆角矩形 + 顶部时间/电量假 UI）、轻微透视倾斜（2°–4°）、摩尔纹（CSS repeating-gradient 程序生成）、对焦呼吸（0.5px blur 脉动）、手抖（±1px 低频 keyframes）。
- **全部为 CSS/SVG 原创质感模拟，不含任何真实盗摄画面**（红线见 §10）。

**C2 满座同类**（厅里有谁）：
- 前排观众剪影：一排低模牛头背影，姿态各异——歪头的、笑到后仰的、举着手机拍的、举荧光棒的。剪影纯黑 `#141414`，只靠轮廓表达。
- 笑声弹幕：横穿屏幕的文字流。词库（原创，玩公开报道里的梗结构）：
  `哈哈哈哈哈哈` / `牛来了！！` / `见证历史` / `这不叫牛来，这叫胡来` / `全体起立` / `十年后你会看懂的` / `根本没人管盗摄哈哈哈` / `排片 +1` / `比我上周写的 CSS 强` / `牛市信仰充值成功`
- 影厅氛围光：画面四角 vignette + 银幕反打的冷光渐变。
- **禁忌**：弹幕永不覆盖输入框、代码块、diff 区；单次爆发 ≤ 2 秒 ≤ 6 条。

## 5. 制作管线

| 轨道 | 方式 | 覆盖 | 理由 |
|---|---|---|---|
| **T1 代码手搓 SVG** | 手写矢量 + `feTurbulence`/`currentColor` | 约 70%（印章、图标、插画、卡片） | 体积 KB 级、主题联动、可 diff、最贴「纯手搓」人设 |
| **T2 程序化生成** | `scripts/gen-cow.mjs` 等 Node 脚本，seed 固定，产物提交 | 低模牛/狼精灵、动画帧、进度装置 | 「用多边形搭建」的字面实现；改 seed 即换造型 |
| **T3 AI 生成栅格** | 会话内 brandkit / imagegen 技能出图，人工审看后入库 | 仅 P2 的 2–3 张大图（三幕背景、个别卡底） | 效率高，但与「拒绝 AI」人设相悖——**默认最小化使用**，README 的自嘲句（"本插件由 AI 手搓"）已为其留了位置；若要人设纯粹可整体替换为 T1/T2（待定决策 #1） |

**工程约束**（与插件既有承诺一致）：

- 保持 `dependencies` / `devDependencies` 全空：压缩用 `npx svgo` 一次性执行，不进 manifest。
- 体积预算：P0 全内联 ≤ 60KB；P1 结束 assets/ ≤ 1.8MB；P2 结束全仓 ≤ 3MB。单 SVG ≤ 30KB，单 WebP ≤ 300KB。
- `scripts/check.mjs` 扩展三条校验：manifest 引用完整性（无死链、无孤儿文件）、体积红线、SVG 内不得含外链/脚本。

## 6. 技术接入

### 6.1 素材托管

- P0：少量小图标与印章直接内联在 `lib/client.js`（字符串 SVG）。
- P1 起：宿主半部按 dsh-status-rotator 的先例注册路由 `GET /plugins/niulai/assets/*` 直读包内 `assets/`（含 content-type 表与 404）；`inject` 增加 `webServer`。README 标注：本插件为 web profile 专用。

### 6.2 目录与清单

```
assets/
  manifest.json        # {id, path, lang, bytes, points[], reducedMotionAlt?}
  poster/  crude/  cinema/  seals/  sprites/  cards/  fx/
```

### 6.3 点位审计（抗上游漂移策略）

| 风险 | 点位 | 依据 |
|---|---|---|
| 稳定 | `<head>` 样式注入、console、**自建全屏 overlay 层（fixed 定位）**、`[role=status]` 状态标签 | 前两者是平台契约；overlay 不依赖上游 DOM；状态标签已在本机实测 |
| 中 | `[data-slot="conversation.composer.dock"]`、`[data-chat-flow]`、空状态区探测 | dsh-ux 等社区插件已在用，有先例但无契约 |
| 高 | 消息气泡内部、设置页卡片注入 | 仅 P2 研究（dsh-market 有 Settings 先例），失败则素材退回 overlay 层 |

**Overlay-first 原则：L2/L3 级素材（弹幕、三幕、名场面卡、盗摄滤镜）一律走自建 overlay，上游改版最多失去锦上添花的 L0/L1 点位，核心体验不塌。**

### 6.4 开关矩阵

| 键 | 值 | 默认 | 作用 |
|---|---|---|---|
| `niulai.art` | `full/calm/off` | `full` | 总档位：calm 只留静态 L0/L1，off 全关 |
| `niulai.danmaku` | `on/off` | `on` | 笑声弹幕 |
| `niulai.audience` | `1` | 关 | 前排观众剪影常驻 |
| `niulai.crude` | `1` | 关 | 正片模式孪生皮肤 |
| `niulai.pirate` | `1` | 关 | 盗摄滤镜 |
| `niulai.premiere` | 自动写 `done` | — | 三幕只自动播一次 |

### 6.5 性能与无障碍红线

- 主线程单次注入 ≤ 50ms；素材懒加载；视口外动画暂停。
- `prefers-reduced-motion`：所有动画素材必须有静帧替身（manifest 强制字段）。
- 弹幕文字带描边保证明暗两主题可读；所有装饰性素材 `aria-hidden="true"`。

## 7. 「震惊」编排

### 7.1 强度分级

| 级 | 定义 | 素材 | 频率红线 |
|---|---|---|---|
| L0 常驻 | 静态、不动、不抢焦点 | 印章、图标、空状态、氛围光 | 无限制 |
| L1 回合级 | 回合内出现，回合结束即收 | 状态动画、进度牌、计数器 | 每回合 ≤ 1 组 |
| L2 会话级 | 完成/错误等事件触发 | 名场面卡、弹幕爆发、彩带、落章 | 单会话 ≤ 2 次弹幕，卡片仅"大任务"触发 |
| L3 仪式级 | 一次性或用户主动开启 | 入场三幕、盗摄滤镜、正片模式 | 自动触发一生一次，其余全部手动 |

### 7.2 触发判定

- 「完成」= 状态标签消失 + 新 assistant 消息落地（已有 MutationObserver 基础设施可复用）。
- 「大任务」= 回合含 ≥ 3 次工具调用或时长 ≥ 60s。
- 「错误」= 错误容器出现（P1 先做保守探测，探测不到就不出，绝不误报）。

### 7.3 入场三幕分镜（NL-01，总长 6.5s，全程可跳过）

| 幕 | 时间 | 画面 | 语言 |
|---|---|---|---|
| 一「场外」 | 0–1.8s | 宣纸底，水墨远山缓入，朱砂印「牛来」落下，楷体小字「治愈系水墨国风」 | A |

## 10. 版权与伦理红线（全素材适用）

1. **零影片素材**：不使用、不改绘、不描摹《牛来》的海报、截图、片段、音频；角色（牛来/云雀/豹拉/狼）按公开文字描述**原创再设计**，低模牛不是影片建模的复刻。
2. **盗摄美学 ≠ 盗摄内容**：C1 质感全部为 CSS/SVG 原创模拟，不含任何真实盗摄画面；文档不鼓励盗摄行为本身，只复刻「那间影厅的空气」。
3. **不仿官方标识**：合规卡默认稳妥档（§8）；不出现国徽、真实证号格式、机构名。
4. **真实人物**：不使用导演母子的肖像、照片、姓名玩梗；对二人的提及仅存在于 README 资讯区且保持敬意（名场面卡 2 是敬意锚点）。
5. **台词**：维基明确条目未收录影片台词；本计划所有卡面文案、弹幕词均为原创的「台词式文案」。
6. AI 生成素材（若启用 T3）在 `CREDITS.md` 逐张标注。
